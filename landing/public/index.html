CORE RESEARCH CONTRIBUTIONS

Six Architectural Innovations

Each contribution addresses a fundamental limitation of traditional churn prediction systems.

Universal Schema Intelligence

PROBLEM: Fixed schemas require manual preprocessing per industry.
INNOVATION: Semantic resolution maps arbitrary columns to canonical fields automatically.
VALUE: One framework handles any CSV without industry-specific code.

Business Concept Reconstruction

PROBLEM: Raw features don't map to business meaning.
INNOVATION: Five universal concepts reconstructed from any schema.
VALUE: Predictions grounded in business language, not ML jargon.

Semantic Feature Resolution

PROBLEM: Column name variations break pipelines.
INNOVATION: Alias resolution with confidence scoring.
VALUE: Robust against typos, casing, and naming conventions.

Adaptive Model Routing

PROBLEM: One model cannot handle all data quality levels.
INNOVATION: Coverage + concept confidence + quality gate select the optimal path.
VALUE: Graceful degradation instead of silent failure.

Knowledge-Driven Reasoning

PROBLEM: Business rules are hardcoded in ML pipelines.
INNOVATION: YAML-based knowledge base with cross-validation.
VALUE: Domain experts update rules without touching ML code.

Prediction Explanation Layer

PROBLEM: Probabilities alone are not actionable.
INNOVATION: Every prediction becomes a business narrative with evidence.
VALUE: Stakeholders understand WHY, not just WHAT.

SYSTEM ARCHITECTURE

Four-Boundary Product Architecture

The deployed platform follows one clear path: Frontend -> API -> Framework Mapper -> UCIF Framework. The core framework remains in universal_churn, while the API and mapper expose it safely to the web UI.

1

Frontend Workspace

INPUT: CSV + selected industry + optional JSON context OUTPUT: API request

Provides upload, manual industry selection, CLI output projection, entered comparison, reports, and decision-support views.

2

API Contract Layer

INPUT: Frontend request OUTPUT: Stable execution contract

Owns uploads, analysis execution, health, prediction, decision, context, mapper, report, and CLI-output endpoints.

3

Framework Mapper Boundary

INPUT: UCIF execution evidence OUTPUT: UI-ready API JSON

Maps coverage, quality, routing, predictions, adaptive business context, decision intelligence, diagnostics, and reports into frontend-safe contracts.

4

UCIF Framework Engine

INPUT: Dataset + sector/context OUTPUT: Intelligence evidence

The universal_churn package owns semantic intelligence, coverage, routing, prediction, explanation, ABIL, decision intelligence, and report generation.

5

Semantic Intelligence

INPUT: Dataset columns OUTPUT: Column meaning + confidence

Detects domain evidence, validates context, builds semantic graph evidence, and supports manual industry override when automatic detection is wrong.

6

Adaptive Routing and Prediction

INPUT: Coverage + quality OUTPUT: Pipeline + predictions

Routes to sector or universal execution, scores customer-level churn risk, and avoids false all-row churn summaries.

7

Adaptive Business Intelligence

INPUT: Optional JSON context OUTPUT: Business impact evidence

Evaluates external context JSON and surfaces business impact, signal count, dominant driver, and recommendation influence.

8

Decision and Reporting Output

INPUT: All evidence OUTPUT: CLI output + comparison + reports

Delivers readable CLI-style output, comparison metrics, decision recommendations, and stakeholder-ready reports.
