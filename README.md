# 📖 What is UCIF?

The **Universal Churn Intelligence Framework (UCIF)** is an enterprise-grade AI Decision Intelligence Platform that enables organizations to analyze customer churn across multiple industries using a single intelligent framework.

Unlike conventional churn prediction systems that only generate a binary prediction, UCIF performs a complete end-to-end intelligence pipeline—from understanding the dataset to recommending business actions.

UCIF is designed around the philosophy that **prediction alone is not enough**. Every prediction should be measurable, explainable, trustworthy, and actionable.

The framework combines machine learning, adaptive routing, business reasoning, explainable AI, and executive decision intelligence into a unified platform that can be deployed through a CLI, REST APIs, or an enterprise web application.

---

# 🎯 Why UCIF?

Traditional churn prediction systems generally answer one question:

> **"Will this customer churn?"**

UCIF answers several critical business questions before making a prediction:

- ✅ Is the uploaded dataset suitable for prediction?
- ✅ How complete is the dataset?
- ✅ Which business concepts can be reconstructed?
- ✅ Is the prediction technically reliable?
- ✅ Which prediction strategy should be used?
- ✅ Why is the prediction being made?
- ✅ What business evidence supports it?
- ✅ What should decision-makers do next?

This transforms predictive analytics into a complete **AI Decision Intelligence Platform**.

# 🚀 Key Capabilities

### 🧠 Universal Dataset Intelligence

Automatically understands datasets from multiple industries without requiring fixed column names.

Supported capabilities include:

- Schema Resolution
- Canonical Field Mapping
- Semantic Column Matching
- Feature Recovery
- Missing Feature Detection

---

### 📊 Coverage Intelligence

Measures how much useful business information exists within a dataset.

Instead of simply counting columns, UCIF evaluates whether critical business concepts are sufficiently represented before allowing prediction.

Outputs include:

- Coverage Score
- Coverage Band
- Missing Critical Features
- Semantic Feature Recovery
- Coverage Explanation

---

### 🎯 Concept Confidence

Determines whether important business concepts can actually be reconstructed from the available data.

Examples include:

- Customer Loyalty
- Engagement Level
- Satisfaction Signals
- Support Friction
- Recurring Commitment

This ensures predictions remain business-aware rather than purely statistical.

---

### 🛡 Quality Intelligence

Performs automated validation before prediction.

Quality checks include:

- Target Leakage Detection
- Duplicate Detection
- Missing Value Analysis
- Column Validation
- Data Consistency Checks

Only high-quality datasets proceed to prediction.

---

### 🔀 Adaptive Model Routing

UCIF intelligently selects the most appropriate prediction strategy.

Depending on dataset quality and business context, the framework automatically chooses between:

- Full Sector Model
- Universal Model
- Refusal (when prediction would be unreliable)

This prevents low-quality predictions from reaching business users.

# 🏛️ Architectural Principles

UCIF is built around several core engineering principles:

- **Modular Design** — Independent framework, backend, and frontend layers.
- **Separation of Concerns** — Business intelligence remains inside the framework; orchestration stays in the backend.
- **Extensibility** — New industries and AI domains can be added without redesigning the architecture.
- **Explainability** — Every prediction is accompanied by business reasoning and supporting evidence.
- **Enterprise Readiness** — REST APIs, modern frontend, deployment support, and scalable architecture.
- **Framework Independence** — The `universal_churn` engine can be consumed via CLI, FastAPI, or future integrations without modification.

# 💻 Option 2 — Run UCIF Locally

Clone the repository:

```bash
git clone https://github.com/GLNVaibhav/Churn_Predictor.git
cd Churn_Predictor
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Start the backend:

```bash
uvicorn backend.api.app:app --reload
```

Start the frontend:

```bash
cd frontend
npm install
npm run dev
```

The local deployment is intended for contributors, development, debugging, and extending the framework.
